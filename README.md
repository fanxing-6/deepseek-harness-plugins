# DeepSeek 插件

通过 DeepSeek Harness 插件接口提供语音输入、手机协同、移动端布局和局域网 HTTPS。每个插件保存在独立文件夹中。

| 目录 | 功能 |
| --- | --- |
| `plugins/dsh-volcengine-asr` | 豆包 WebSocket 实时语音识别、音量条、左侧语音／键盘切换、中间长按说话与松手自动发送 |
| `plugins/dsh-mobile-collaboration` | 全局手机协同入口与面板、会话及页面双向切换、手机原始画面、远程输入与滚动、手机前台保持亮屏 |
| `plugins/dsh-mobile-ui` | 独立移动端布局、输入法组合输入处理、键盘高度适配 |
| `plugins/dsh-lan-access` | 局域网 HTTP／HTTPS 入口、WebSocket 转发、Cloudflare DNS 验证与 Let’s Encrypt 证书续期 |

## 构建

使用 Node.js 24 和 npm，在仓库根目录运行：

```sh
npm ci
npm run build
npm run check
```

语音输入和手机协同插件的 `client-source.jsx` 是前端入口，构建生成各自的 `client.js`。独立移动布局插件直接维护 `client.js`。构建产物和依赖目录由本地生成。

## 配置

当前代码用于官方 DeepSeek Harness 桌面版 `0.2.2-rc.1`，涉及 DSH 的插件注册、Typert 服务和界面插槽。应用升级后需要重新检查接口与界面样式兼容性。

1. 完成上述依赖安装与构建。
2. 将 `profile.package.example.json` 中的依赖条目合并到目标 DSH profile 的 `package.json`，把示例路径换成插件的实际绝对路径。保留 profile 已有的其他配置。Windows 路径使用正斜线，例如 `C:/path/to/deepseek-harness-plugins/plugins/dsh-volcengine-asr`。
3. 将 `cordis.patch.example.yml` 中所需插件的条目合并到 profile 的 `cordis.patch.yml`。按安装环境填写局域网地址、端口与访问域名，并由 DSH 完成 profile 依赖解析后重新载入应用。
4. 语音插件通过 DSH 凭据服务读取 `VOLCENGINE_ASR_API_KEY`。在目标环境的 DSH 凭据配置中保存实际 API Key。
5. 使用 HTTPS 插件时，复制其 `https-config.example.json` 为同目录下的 `https-config.json`，填写域名、局域网地址、Cloudflare Zone ID、Token 文件路径和证书目录。证书签发需要该域名的 DNS 管理权限；当前签发流程会接受 Let’s Encrypt 服务条款。
6. 手机通过配置好的 HTTPS 地址访问 DSH，允许麦克风权限。电脑左侧栏底部的「手机协同」按钮打开全局协同面板；左侧栏收起时入口显示在窗口右下角。面板显示已连接的手机，无设备时显示可复制的连接地址。
7. 原始画面需要 Android 手机使用 Chrome，并与宿主电脑的 Android Platform Tools 完成无线调试配对。保持无线调试开启。将协同插件的 `capture-config.example.json` 复制到用户主目录下的 `.dsh/mobile-collaboration-capture.json`，填写 `adbPath` 的完整路径。可选 `keyPath` 指定已有授权的 ADB 私钥文件，`serverPort` 指定 ADB 服务端口。凭据文件仅保存在对应电脑上。

`dsh-mobile-collaboration` 已包含移动端紧凑布局。需要单独的移动布局时可以选用 `dsh-mobile-ui`，它使用当前 Mac 桌面版对应的界面样式标识。每个页面只启用一套移动布局插件。

## 交互与运行边界

- 输入区域左侧固定语音／键盘切换按钮，中间在文字输入框与长按语音区域之间切换。
- 两种输入模式均保留模型、权限和附件入口，语音模式可直接选择模型。
- 按住说话时向上移动 56 像素进入「松开取消」，滑回按下时的按钮区域恢复「松开发送」。取消会清除本次转写并保留已有草稿，手机协同使用相同手势。
- 松手确认发送后继续接收识别结果，最终结果到达时自动提交，并检查 DSH 是否清除了已提交草稿。识别连接中断时自动提交已收到的文字，同时保留错误说明和语音记录。尚无识别文字时保留录音并提示重新识别；发送状态无法确认时保留内容并提示检查对话或待发送队列。
- 录音音频、每次返回的转写和提交状态保存在当前浏览器的 IndexedDB。语音模式下的「语音记录」可以跨会话查看、发送已有文字、重新识别录音以及查看识别过程。网页刷新后记录仍可读取；不同浏览器和访问地址分别保存，清除站点数据会移除这些记录。
- 当前单次音频上限为 120 秒；达到上限后结束音频上传，松手提交已有识别内容。
- 开启手机协同后，两端同步当前会话，包括尚未发送消息的新会话，以及插件、自动化任务等全局页面。切换页面保持协同连接，手机刷新后恢复同步。
- 全局协同面板通过 Chrome DevTools Protocol 接收手机浏览器渲染的 PNG 原始画面，保留网页字体、排版和可视内容，并根据电脑屏幕的像素密度进行高质量缩放。点击、滚动、触摸和键盘操作发送到手机浏览器，图片通过网页上传入口传入。关闭面板结束协同。画面更新速度受局域网和图像传输速度影响。
- 协同自动接续最近打开或返回前台的手机；旧网页关闭、进入后台或断网时，新手机可以继续同步。每条画面与状态消息标记来源设备，切换后忽略旧设备的延迟消息。电脑主动断开时暂停自动接续。
- 手机代码块、行内代码和语法着色内容统一使用 700 字重、16px 字号，代码块使用 20px 行高，并提供浅色与深色高对比度配色。
- 手机网页在前台时通过 Screen Wake Lock 保持亮屏，关闭协同面板后仍然有效；网页进入后台或关闭时释放请求，返回前台重新申请。浏览器需要支持 Screen Wake Lock，系统省电策略仍可能拒绝请求。
- 局域网入口复用宿主会话权限，能够连接该入口的设备可访问对应 DSH 功能。HTTPS 证书由 Cloudflare DNS 验证签发，每日检查续期。

## 本地配置与发布内容
